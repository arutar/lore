# Иконки Lore

## Общие требования

- Основной знак Lore — фирменный glyph из `svg/lore-glyph.svg` на синем фоне `#58A6FF`, цвет знака `#0D1117`.
- Операции обозначаются отдельным цветным значком в правом нижнем углу, без замены основного знака.
- Не использовать только цвет для передачи состояния: форма значка должна различаться.
- Предпочтительный исходник — SVG. Для Windows дополнительно нужны PNG и ICO.
- PNG: 16, 20, 24, 32, 48 и 256 px.
- ICO: 16, 20, 24, 32, 48 и 256 px в одном файле, RGB/RGBA, без потери цвета и с прозрачным фоном там, где это предусмотрено дизайном.
- Маленькие размеры 16–20 px требуют отдельной проверки читаемости, а не только масштабирования 256 px.

## Explorer: действия

| Действие | Имя файла | Изображение |
|---|---|---|
| Общий пункт Lore / Lore Companion | `lore` | Основной знак Lore |
| Clone | `clone` | Знак Lore + зелёная стрелка вниз |
| Sync | `sync` | Знак Lore + зелёные круговые стрелки |
| Commit | `commit` | Знак Lore + зелёная галочка |
| Stage selected paths | `stage` | Знак Lore + синий плюс |
| Status | `status` | Знак Lore + информационный символ или список |
| History | `history` | Знак Lore + фиолетовые часы |
| Acquire locks | `lock` | Знак Lore + серый закрытый замок |
| Release locks | `unlock` | Знак Lore + зелёный открытый замок |
| Выбор каталога | `folder-open` | Папка; можно использовать системную иконку Windows |

## Explorer: overlays состояния

| Состояние | Имя файла | Изображение |
|---|---|---|
| Normal / clean repository root | `success` | Зелёная галочка на корневой папке репозитория; обычные clean-файлы без overlay |
| Modified | `overlay-modified` | Оранжевый карандаш или точка |
| Staged | `overlay-staged` | Синий плюс |
| Conflicted | `overlay-conflicted` | Красный восклицательный знак |
| Locked | `overlay-locked` | Закрытый замок |
| Ignored | `overlay-ignored` | Серая перечёркнутая или минус-иконка |
| Staged + modified | `overlay-staged-modified` | Плюс и карандаш в одном значке |

Overlay должен читаться при 16 px и не закрывать основную иконку файла. Размещение — нижний левый угол, как у TortoiseSVN.

## Окна Lore Companion

| Окно | Иконка |
|---|---|
| Clone repository | `clone` |
| Sync repository | `sync` |
| Commit changes | `commit` |
| Stage paths | `stage` |
| Repository status | `status` |
| Revision history | `history` |
| Acquire locks | `lock` |
| Release locks | `unlock` |

Та же иконка используется в заголовке окна и в заголовочном блоке. Для заголовочного блока нужен вариант 32–48 px.

## Служебные состояния интерфейса

| Состояние | Имя файла | Изображение |
|---|---|---|
| Success | `success` | Зелёная галочка |
| Warning | `warning` | Янтарный треугольник |
| Error | `error` | Красный крест или круг с восклицательным знаком |
| Information | `info` | Синий информационный символ |
| Running operation | `progress` | Только если используется визуальный spinner; обычный progress bar иконки не требует |
| Empty repository/catalog | `empty` | Нейтральная пустая папка |
| Settings | `settings` | Шестерёнка, если появится отдельное окно настроек |

## Приложение и установка

| Назначение | Имя файла | Примечание |
|---|---|---|
| Основная иконка приложения | `app` | Основной знак Lore; варианты для ярлыка, installer и uninstaller |
| Ярлык Lore CLI | `cli` | Знак Lore + терминал, если будет отдельный ярлык |
| Обновление клиента | `update` | Знак Lore + стрелка обновления |

## Стандартные элементы, для которых своя иконка не нужна

- Cancel, Close и OK — только текст и стандартное поведение Windows.
- Browse использует текст `...` либо системную папку.
- Системные ошибки и предупреждения не должны быть отдельными popup, если ошибка отображается внутри окна операции.

## Приёмка

Проверять на Windows 11:

- тёмная и светлая темы;
- масштабирование 100%, 125%, 150% и 200%;
- Explorer menu и submenu;
- overlays для всех состояний;
- заголовки окон и ярлыки;
- отсутствие потери цвета, прозрачности и обрезанных краёв;
- отсутствие размытия при 16 px.
