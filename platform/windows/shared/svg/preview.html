Lore Windows icon set

Source SVGs in platform/windows/shared/svg, generated by node build-icons.mjs from the master Lore mark (lore-glyph.svg). The main sign is the Lore mark on #58A6FF drawn in #0D1117; an operation adds a coloured badge in the lower right corner and never replaces the sign; a state overlay sits in the lower left corner and keeps the file icon visible. Every state differs by shape, not only by colour.
