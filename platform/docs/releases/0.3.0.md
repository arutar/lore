## What changed

Lore Platform 0.3.0 lets AI agents read repositories over MCP, and makes every WebUI page fit a phone.

**MCP for AI agents**

- The control plane answers the Model Context Protocol at `<WebUI address>/mcp`. Claude Code,
  Cursor, Hermes and any other MCP client connect with the address and a personal token.
- Read-only by design: `list_repositories`, `get_repository`, `list_files`, `file_info`,
  `read_text`, `download_link`, `history`, `revision_changes` and `list_locks`. No tool changes or
  deletes anything.
- Files: `file_info` returns metadata only and tells UTF-8 text, other text and binary files apart.
  `read_text` returns numbered lines in parts, searches one file (`pattern`, plain or a regular
  expression) and reads other encodings when asked (`encoding`, such as `windows-1251`).
  `download_link` gives a link that downloads any file for 10 minutes without a token.
- Tokens: each person creates their own under **MCP** in the left menu, optionally limited to some
  repositories and with an expiry. Every request needs one, also for public repositories. A token
  reads what its owner may read at that moment. Only a SHA-256 of it is stored. Administrators see
  and revoke everyone's tokens.
- **Users and groups** has an **MCP** switch for local accounts, Active Directory people and
  groups, on by default. A personal setting wins over groups; without one, any group that allows
  MCP is enough. Switching off takes effect on the next call.
- Token creation and revocation, switch changes and download links are in the audit log.
- Limits: at most 8 calls per token at once (`LORE_MCP_CONCURRENCY`), 1 MB of text per `read_text`
  call (`LORE_MCP_MAX_READ`), 10-minute download links (`LORE_MCP_LINK_TTL`).
- Guide: [platform/docs/mcp.md](../mcp.md). Decision record: [ADR-0002](../decisions/0002-mcp.md).

**WebUI on a phone**

- History puts the revision number and ID on a second line instead of cutting the message to a few
  letters.
- The home page shows the top bar, the repository list and then the client downloads in one scroll;
  before, only the list was there.
- Inactive repository tabs shrink to icons, so Access and Settings stay reachable.
- Locks, Access, Users and Audit show each row as a card; Files drops the last-change column; the
  search palette and dialogs fit the screen.
- The repository header keeps the name and badges beside the icon with the description below; the
  download buttons fill the row.

**Server and setup**

- `LORE_MCP=off|internal|on` (`sh setup.sh --mcp …`, `.\setup.ps1 -Mcp …`), `off` by default.
  `internal` answers only `LORE_MCP_NETWORKS` (`--mcp-networks "10.0.0.0/16;192.168.0.0/24"`,
  `-McpNetworks …`), which setup requires with it.
- Caddy passes the client's own address to the control plane in `X-Real-IP` and drops a
  client-supplied `True-Client-IP`.
- Database migration `013_mcp.sql` adds the token and link tables and the MCP switches.

**Upgrading**

Deploy the 0.3.0 server bundle and images and run setup. MCP stays off until you run setup with
`--mcp internal --mcp-networks "…"` or `--mcp on`. The Windows client and the Linux CLI are unchanged.
