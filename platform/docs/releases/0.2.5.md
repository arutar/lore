### What's new

This release shortens the wait for large selections in the Windows Commit dialog and shows progress after you click Commit.

**Faster selection on large working copies.** The dialog resolves the selected paths once per scan. On a working copy with 703,009 changed files, the average time from opening the dialog to seeing every file selected and the Commit button enabled fell from 97.08 s to 71.90 s (26% less waiting). Each build was timed twice after warm-up on the same working copy. Selecting a folder still includes its descendants and any files already staged elsewhere.

**Visible commit and upload progress.** After you click Commit, the dialog hides the file list and description and shows the current operation. Progress includes file counts, transferred data and a percentage when Lore reports a total. If the operation fails, the dialog restores the description and lets you inspect the log before retrying.

**Verification.** All 37 offline Windows client tests passed. In a separate LAN test of the progress indicator before the selection change, the GUI staged, committed and pushed 703,009 files (2.17 GiB) in 5 min 33 s from the Commit click. An independent clone matched every file byte for byte.

**Upgrading.** Install the 0.2.5 Windows MSI over your previous version to get the updated Commit dialog.
