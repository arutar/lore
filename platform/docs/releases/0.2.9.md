## What changed

Lore Platform 0.2.9 removes a delay that 0.2.8 added at the end of every push.

**Pushing**

- The server no longer forces its whole store to disk each time it records the progress of a
  push. Right after a large upload that took seconds per record: a commit through the Windows
  Commit window spent 15–27 s between "Sending revision" and success with 0.2.8, and 3–7 s with
  0.2.9 (200,000 files on the same server, two runs each). Creating the revision takes as long as
  before.
- If the server restarts and has lost the record of a push in progress, the client starts the push
  again under the same id instead of failing.

**Upgrading**

Deploy the 0.2.9 server bundle and images. The 0.2.8 Windows client and Linux CLI work with a 0.2.9
server; update them to get the restart after a lost push record.
