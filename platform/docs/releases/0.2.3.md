### What's new

**Windows client**
- **Clearer Commit list.** Each file shows its change by colour instead of a letter: a stripe at the row's edge and the colour of its name, green for a new file, yellow for a changed one, red and struck out for a deleted one. The legend under the list says which is which.

**Upgrading:** Windows: install the new MSI over the previous one. The server is unchanged since 0.2.2; updating it is optional.
