### What's new

**Windows client**

The Commit window pages through large working copies and searches across folders. It keeps the selection in the native client, excludes files locked by another user and leaves newly discovered files out of the revision when they appeared after the list opened. A fresh clone can fetch missing metadata during its first scan.

**Tested with over 700,000 files.** On Windows, the Commit window listed and selected all 703,009 new files (2.17 GiB) in 57.6 s. After clicking Commit, the first upload to an empty LAN repository took 5 min 28 s, including staging, creating the revision and pushing it. The full operation took 6 min 26 s from opening the dialog. A separate clone verified the contents of every file.

**Repository settings**

Administrators can delete a repository from the Danger Zone in its Settings tab. The confirmation dialog requires the full repository name. The server checks the name and sends the deletion to Lore under the administrator's identity.

**Upgrading**

Install the Windows MSI over the previous version. Update the server bundle and control-plane image to 0.2.4 to enable the new repository settings.
