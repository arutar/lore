## What changed

Lore Platform 0.2.11 offers the client on the WebUI's home page and gives the themes more colour.

**WebUI**

- The home page has an **Install the client** card. Its cover shows the client's version, which
  matches the server's. Below it, one row per system: Windows (**Download MSI** and the zip) and
  Linux (**Download .tar.gz**, x86_64 or aarch64, and a button that copies a ready `curl … && tar …`
  command). A label says whether the files come from GitHub or from this server. **How to connect**
  follows.
- Themes v3, the same nine themes with more colour:
  - repository icons and avatars are filled with one of six colours per theme, picked to suit
    the theme and kept for the same name; initials and icons on them have a contrast of at
    least 4.9:1;
  - **Private** and **Public** are labels: amber with a lock, green with a globe;
  - the selected repository has a bar in the accent colour, the current section in the left
    menu is filled with it, the current tab's icon and count take it, and the counters on the
    home page have a coloured top edge;
  - Sky's background is about 30 % darker.
- The revision panel shows the parent under the revision's signature, on the right, so the
  header takes one line less.

**Server and setup**

- The control plane serves `<data>/downloads/` at `/downloads/` (no sign-in needed: these are
  the release's public files). Setup writes it on every run from the bundle's new `clients.tsv`.
- `LORE_CLIENT_DOWNLOADS` (`sh setup.sh --client-downloads …`, `.\setup.ps1 -ClientDownloads …`):
  - `online`, the default: the home page links to the release's files on GitHub;
  - `offline`: setup keeps the four files on the server (about 340 MB), taken from a `clients/`
    folder next to it or downloaded from the release, each checked against its SHA-256;
  - `off`: the home page links to the releases page.

**Upgrading**

Deploy the 0.2.11 server bundle and images, and run setup; add `--client-downloads offline`
(`-ClientDownloads offline`) on a network without access to GitHub. The Windows client and the
Linux CLI are unchanged from 0.2.10.
