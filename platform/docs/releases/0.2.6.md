## What changed

This patch updates the Windows client and Linux CLI for people cloning public repositories or sending large commits.

- Public repositories can be cloned by name or ID without signing in. When access is denied, the Windows client offers sign-in and the CLI explains how to authenticate. Closing the Windows sign-in dialog cancels the pending login.
- When a branch push hits the server's request-handler timeout, the client checks the remote branch head. A matching revision confirms the push. If confirmation fails, the Windows client explains that the commit is saved locally and asks you to check server history before retrying.
- We verified a Windows GUI upload of 421,486 files (80.12 GiB) to a separate LAN repository. An independent checkout confirmed the remote revision, and SHA-256 checks matched for four sampled files.
- Maintainers can run PR Validate manually from GitHub Actions.

Install the 0.2.6 Windows MSI or replace your Linux CLI binary to use the fixes.
